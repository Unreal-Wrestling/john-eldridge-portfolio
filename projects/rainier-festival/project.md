The Rainier Mountain Festival project was a print advertising campaign
built to run across four formats: a full-page magazine ad, a newspaper
ad, and two web banner sizes. Same festival, same logo, same visual
language — adapted to the constraints of each medium.

## The full-page ad

The hero piece is a full-page ad with mountain photography as the
background and event details set in a clean grid below. The image does
the selling; the type does the informing.

[[01-festival-full-ad.jpg]]

## The newspaper ad

Newspaper stock eats detail and runs at a smaller scale, so the
newspaper version tightens everything up — shorter columns, heavier
type, less reliance on the photograph and more on the information
hierarchy.

[[02-newspaper-ad.jpg]]

## Web banners

The banner ads condense the campaign into its smallest footprints. A
square box banner and a horizontal leaderboard, each carrying the
festival logo and a single call to action.

[[03-banner-box.jpg]]

[[04-banner-leader.jpg]]

## The logo

The festival logo was the anchor for every piece in the campaign. It
sits in the same position on every format, at a size that reads from
across a page or a screen.

[[05-festival-logo.png]]

The whole campaign was built in InDesign with master pages and
paragraph styles, so changing the date or the event list updated
every format at once.
